## 核心架构速览（V3.0）

```
热环路(在线):  多通道检索融合(sem/sit/sym/out 加权) → taxonomyContext检索咨询 → OOD检测 → 低余量LLM精排 → 5层校准(含元经验标记) → 预测
冷环路(离线):  采样(含meta通道) → 情境-策略锚定(前提分化) → 证据校验 → 双区间验收 → 回写
自动积累:     turn/end → 预过滤 → LLM门(模板5) → 直写入库
自我认知:     检索失败自动sar化(meta经验) → 冷环训练切片 → 检索失败模式簇
权重学习:     通道权重由反馈误差驱动EWMA更新(channel_weights.json)
```

## 关键设计原则

1. **效用优先于语义** — 按"行动-结果"的因果效用聚类，而非文本相似度。
2. **预测误差驱动重建** — 不因数量堆砌，只因"猜错了"才推倒。
3. **双环路解耦** — 热环路毫秒级，冷环路深度计算。
4. **置信度校准** — 五层防护对抗 LLM 过度自信。
5. **LLM 路由是上限，确定性路径是下限** — 模板调用 reasoningEffort off；无路由降级确定性数学。
6. **分化随经验累积自动涌现** — 前提差异不需要标注，≥3 证据下限即分化阈值。
7. **经验自动积累，判断交给 LLM 路由** — 完成轮次自动评估沉淀，纯聊天预过滤。
8. **自我认知参与检索** — 检索前咨询分类体系，低置信路由显式标注。
