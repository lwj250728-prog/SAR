# 技术计划书：面向LLM的动态经验分类与预测认知系统

**版本**：V2.0（基于效用导向与置信度校准）
**核心目标**：模拟人类"基于预测误差驱动分类重建"的有机认知过程，使LLM具备目的性分类、不确定性感知及在线快速迭代能力。

---

## 一、 总体架构设计原则

1. **效用优先于语义**：分类依据从"文本相似性"转向"行动-结果（SAR）的因果效用相似性。
2. **预测误差是重建的第一驱动力**：不因数量堆积而重建，只因"猜错了"且"错得离谱"而触发范式迁移。
3. **双环路解耦**：热环路（在线推理）追求毫秒级响应与诚实的不确定性；冷环路（离线重构）追求深度归因与范式提炼。
4. **渐进式遗忘与验证**：引入时间衰减与沙盒回测，防止系统过度拟合噪声或远古偶然事件。

---

## 二、 核心数据模型设计（PostgreSQL + 向量数据库双写）

| 表名 | 核心字段 | 设计意图 |
| :--- | :--- | :--- |
| **experiences**（主记忆库） | `exp_id`, `situation`(文本), `action_taken`(文本), `actual_outcome`(文本), `action_vector`(浮点数组), **`outcome_vector`**(浮点数组，关键聚类依据), `cluster_id`(整数), `strategy_label`(文本), `timestamp`(时间戳) | 存储完整经历，其中`outcome_vector`用于"效用空间"聚类，而非语义空间 |
| **predictions**（预测日志） | `exp_id`, `predicted_outcome`(文本), `prediction_score`(浮点), `confidence_interval_low/high`(浮点), `calibrated_prob`(浮点) | 记录每次预测的详情，用于后续校准曲线绘制 |
| **temp_strategies**（临时工作区） | `signature_hash`(文本), `trial_action`(文本), `pending_result`(文本空位), `hit_count`(整数), `lifespan`(间隔) | 存储OOD（分布外）新物种的试探性策略，仅存活24小时或N次交互 |
| **calibration_stats**（校准统计） | `confidence_bucket`(如70-80%), `total_count`, `hit_count`, `empirical_accuracy` | 用于终身置信度修正（Platt缩放） |

## 三、 热环路（在线推理引擎）详细流程

**触发条件**：用户输入新情境 → 系统提取`action_taken`向量。

### Step 1：不确定性雷达（OOD检测）
- 检索Top-10相似历史行动向量。
- **数学判定**：若`Top1相似度 < 0.65` 或 `Top1 - Top3得分方差 < 0.1`，标记为潜在OOD。
- **LLM轻量复核**（仅当数学触发时）：询问"此行动是否属于历史模式的合理延伸？"若置信度<60%，确认OOD。

### Step 2：分支路由
- **熟路（低OOD）**：调用检索到的Top-K相似样本，进入**置信度校准模块**（见第五章），生成预测区间。
- **陌路（高OOD）**：**不调用旧分类**。查询`temp_strategies`表。
  - 若命中临时策略 → 直接引用并提醒"此为临时试行方案"。
  - 若未命中 → LLM输出带 **"⚠️ 全新现象"** 标记的实验性方案，并自动创建临时策略存入工作区。

### Step 3：实时反馈注入（异步）
用户执行行动后，异步回调填入`actual_outcome`。系统实时计算`prediction_error`，若误差绝对值>阈值，立即更新该`cluster_id`的累计误差值。

## 四、 冷环路（离线重构管线）执行逻辑

**调度策略**：每日凌晨（T+1）执行局部修补；每周或累计误差簇超40%时执行全局重构。

### 阶段1：数据采样（对抗灾难性遗忘）
- 应用 **时间衰减权重** `W = e^(-λ * Δt)`，优先选取近90天的高误差样本（`error > 0.3`）及簇边界样本。
- **排除**：权重极低（<0.1）且非极端异常的远古样本，避免噪声干扰。

### 阶段2：效用空间重聚类
- 算法：提取采样样本的`outcome_vector`，使用 **层次聚类（Hierarchical Clustering）** 重新划分。
- **完全无视**原始的`Situation`文本语义，仅看结果效用的聚合模式（如：是否都导致"精力耗尽但财务微增"）。

### 阶段3：LLM因果锚定重构（核心Prompt逻辑）
- **硬性约束**：要求LLM必须为每个新簇引用至少**3个不同时间点的支撑证据ID**，若无法找出则标记为"噪点"并剔除。
- **输出格式**：强制生成 **概率决策规则集（JSON）**，包含 `触发条件`、`行动姿态`、`预期效用区间`、`匹配度阈值`。

### 阶段4：沙盒回溯验证（防止负优化）
- 用最近20%的校验集数据代入新分类，计算**模拟预测误差**。
- **生效条件**：新误差 ≤ 旧误差 × 0.85（即降低15%以上）。否则驳回，仅执行局部叶子节点修补。

### 阶段5：原子性回写与知识蒸馏
- 批量更新主库`cluster_id`和`strategy_label`。
- 将新分类逻辑压缩为 **《认知框架摘要》**（<300字），注入热环路的固定System Prompt前缀。

## 五、 置信度校准模块（五层防护）

这是防止LLM"迷之自信"的核心工程层：

| 层级 | 实现方式 | 作用 |
| :--- | :--- | :--- |
| **1. 频次先验植入** | Prompt强制显示"Top-K中M次正向"，要求LLM据此推算基准概率 | 用硬数字约束幻觉 |
| **2. 样本量惩罚** | 后端算法修正：`P_cal = P_raw * (k/50) + 0.5 * (1 - k/50)` | 样本少时强制拉回50%无知线 |
| **3. 区间预测** | 强制输出"80%置信区间"（如 30%~70%）而非单点 | 鼓励模糊时扩大区间 |
| **4. 对抗性挑战** | 输出前强制列举3个独立失败因素并下调概率 | 激活怀疑脑区，降低过度自信 |
| **5. 终身校准跟踪** | 统计各置信度档位的实际准确率，月度生成修正系数注入System Prompt | 闭环自适应修正 |

## 六、 临时工作区（Episodic Scratchpad）生命周期

| 状态 | 触发条件 | 处理动作 |
| :--- | :--- | :--- |
| **创建** | 热环路判定OOD且无历史匹配 | 存入`temp_strategies`，设定24小时TTL |
| **试探匹配** | 新查询向量模糊匹配（相似度>0.5） | 即时将该临时规则注入当前对话System Prompt尾部（前缀微调） |
| **毕业（晋升）** | 命中次数≥3且正向反馈≥2次 | 晋升为主库新簇的初始质心种子（Seed），参与下次冷环路重建 |
| **废弃** | 超时未反馈 / 负向反馈 | 软删除，不作为长期经验 |
| **紧急打断** | 单次反馈结果极端异常（收益/损失极大） | 无视定时任务，立刻触发针对此单样本的局部冷环路修补 |

## 七、 实施路线图（分三阶段落地）

| 阶段 | 周期 | 核心交付物 | 验收标准 |
| :--- | :--- | :--- | :--- |
| **Phase 1：基础骨架** | 第1-2周 | PostgreSQL+向量库建表；实现SAR三元组提取Pipeline；实现基础向量检索与硬编码阈值OOD检测 | 能区分"明显已知"与"明显未知"输入，误差值可写入数据库 |
| **Phase 2：动态能力** | 第3-5周 | 实现热环路置信度校准（五层中至少前3层）；实现冷环路采样+层次聚类+沙盒验证；搭建Celery异步任务调度 | 能在一个模拟数据集上展示"预测失败→局部修补→误差下降"的完整闭环 |
| **Phase 3：高阶智能** | 第6-8周 | 实现临时工作区全生命周期；接入LLM因果锚定Prompt链；上线终身校准跟踪仪表盘 | 同一问题连续追问时，系统能表现出现学现卖的"瞬时绑定"能力，且校准曲线显著优于原生LLM |

## 八、 关键风险与应对策略

| 风险点 | 影响 | 缓解措施 |
| :--- | :--- | :--- |
| **LLM因果幻觉（乱归因）** | 重构出虚假分类，导致系统退化 | 强制"3条证据链"硬约束；后端用向量距离二次核验支撑证据 |
| **冷环路计算成本爆炸** | 每周全量重聚类不可行 | 仅采样"边界+高误差"样本（<总量15%），配合时间衰减过滤远古数据 |
| **频繁无效重建** | 系统震荡，预测误差不降反升 | 严格执行"沙盒验证15%改善阈值"，不达标自动回滚并记录失败原因 |
| **临时工作区污染** | 偶发运气被当作规律固化 | 设置"命中次数≥3"的晋升门槛，且晋升前需经过轻量级沙盒测试 |

## 九、 成功指标（KPI）定义

1. **预测校准度（Calibration Error）**：各置信度档位的实际准确率与预测概率的均方根误差（目标 < 0.1）。
2. **重建有效率**：冷环路触发后，通过沙盒验证的比例（目标 > 70%）。
3. **OOD识别召回率**：人工标注的"真正全新样本"被系统标记为OOD的比例（目标 > 85%）。
4. **临时策略晋升准确率**：从`temp_strategies`晋升为主库种子的策略，后续验证真实有效的比例（目标 > 75%）。
