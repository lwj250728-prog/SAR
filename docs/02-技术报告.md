# 技术报告：基于预测误差驱动的LLM动态认知架构
## （Dynamic Cognitive Architecture via Prediction-Error Drive, DCA-PED）

**报告编号**：TR-2026-08-11-V2.0
**关键词**：大语言模型、认知架构、在线学习、置信度校准、效用空间聚类、分布外检测（OOD）

---

## 1. 引言与问题形式化

### 1.1 背景
当前基于RAG（检索增强生成）的LLM应用将人类记忆视为"静态语料库"，其检索逻辑基于语义空间的余弦相似度。这违背了认知心理学中的 **"效用驱动"** 原则——人类存储经历时，编码的是 **情境-行动-结果（SAR）** 的因果转移函数，而非文本特征。

### 1.2 问题形式化
设时间步 $t$ 的经验为 $e_t = (S_t, A_t, R_t)$，其中：
- $S_t$：情境上下文；
- $A_t$：采取的行动策略；
- $R_t$：观测到的结果效用（标量或高维向量）。

传统聚类目标：$\min \sum ||\text{Emb}(S_t) - \text{Centroid}||^2$（语义相似）。

**本架构目标**：$\min \sum ||\text{Emb}(R_t) - \text{Centroid}_{R}||^2 + \lambda \cdot \text{Prediction\_Error}$（效用相似 + 预测精准）。

**核心假设**：分类的生命周期由 **预测误差（Prediction Error, PE）** 驱动。当且仅当 $E[PE | \text{Cluster}_i] > \theta$ 时，触发该簇的范式重构。

---

## 2. 系统顶层架构

系统采用 **"热-冷"双环路分离架构**，确保在线推理的低延迟与离线重构的深度计算互不阻塞。

```
输入(新经验) → 热环路(在线推理)
    ├── 低置信度/高OOD → 临时工作区(Scratchpad)
    └── 预测与反馈 → 数据库(向量+关系)
数据库 → 采样触发 → 冷环路(离线重构)
冷环路 → 新范式 → System Prompt(认知摘要注入)
临时工作区 → 晋升/废弃 → 数据库
真实结果回调 → 误差计算 → 热环路
```

---

## 3. 核心模块详细设计

### 3.1 数据抽象层（Schema Definition）
采用 **双向量存储策略**，分别对应"行为姿态"与"结果效用"。

- **Action Embedding Model**：`sentence-transformers/all-MiniLM-L6-v2`（轻量，用于快速检索行为模式）。
- **Outcome Embedding Model**：`OpenAI/text-embedding-3-small`（维度更高，用于精细刻画结果的多维效用，如：情绪价 + 物质收益 + 精力消耗）。

**关键数据结构（JSON Schema）**：
```json
{
  "exp_id": "uuid",
  "sar": { "s": "string", "a": "string", "r": "string" },
  "embeddings": { "action": "float[384]", "outcome": "float[1536]" },
  "metadata": { "cluster_id": "int", "timestamp": "iso8601", "decay_weight": "float" }
}
```

### 3.2 热环路：在线推理与不确定性量化（Uncertainty Quantification）

#### 3.2.1 分布外（OOD）检测算法
定义检索到的 Top-K 相似度集合为 $D = \{d_1, d_2, ..., d_K\}$，其中 $d_1 \geq d_2 \geq ...$。

- **陌生指数（Strangeness Index, SI）**：
  $$SI = \frac{\text{Var}(D)}{\text{mean}(D) + \epsilon}$$
  若 $SI > \tau_{si}$ 或 $d_1 < \tau_{sim}$，触发LLM复核。

#### 3.2.2 置信度校准算法（Platt缩放变体）
**Step 1（Prompt频次注入）**：检索出相似样本后，Prompt强制注入统计信息："在最近10次类似行动中，成功次数为M"。

**Step 2（后验收缩）**：LLM输出原始概率 $P_{raw}$，系统根据检索基数 $K$ 执行贝叶斯收缩：
$$P_{cal} = \frac{K}{K + \alpha} \cdot P_{raw} + \frac{\alpha}{K + \alpha} \cdot 0.5$$
其中 $\alpha=50$（经验常数，代表对"无知先验"的信任强度）。

**Step 3（区间输出）**：强制LLM输出80%置信区间 $[L, U]$，要求 $U - L \geq 0.2$ 以鼓励模糊表达。

### 3.3 临时工作区（Episodic Scratchpad）生命周期管理
这是解决"冷启动"和"罕见事件记忆"的关键工程组件。

- **状态机**：`Draft(创建)` → `Active(匹配中)` → `Graduated(晋升)` / `Expired(废弃)`。
- **晋升条件**：命中次数 $\geq 3$ 且正反馈率 $\geq 66.7\%$。
- **注入机制**：在热环路的System Prompt尾部动态追加临时规则，利用LLM的上下文前缀（In-Context Prefix）实现即时微调，**不修改模型权重**。

### 3.4 冷环路：离线范式重构（Offline Reconstruction Pipeline）

#### 3.4.1 带遗忘权重的采样策略
为避免计算爆炸和过拟合于历史噪声，采样权重函数定义为：
$$W(e_i) = e^{-\lambda \cdot \Delta t_i} \cdot \mathbb{1}_{\{PE_i > \theta_{pe}\}}$$
仅当预测误差 $PE_i$ 超过阈值且时间衰减权重未归零时，样本被纳入重构数据集。

#### 3.4.2 效用空间聚类算法
采用 **层次凝聚聚类（Agglomerative Clustering）**，距离度量使用 **1 - Cosine Similarity** 作用于 `outcome_vector`。

- **停止准则**：当簇间最小距离大于预设阈值 $\delta_{merge}$ 时停止合并，确保分类的精细度。

#### 3.4.3 LLM因果锚定（Causal Grounding）约束
在重构Prompt中施加硬约束（Hard Constraint）：

> **系统约束**：生成的每一个新簇必须附带 `supporting_evidence` 列表（至少3个`exp_id`）。
> **后端校验**：提取这3个证据的 `outcome_vector`，计算两两之间的最大余弦距离。若 $max\_dist > 0.85$，则该簇被视为"幻觉因果"，**强制驳回**并记录异常日志。

#### 3.4.4 沙盒回溯验证（Backtesting）
将新分类框架应用于时间线上的 **校验集（最近20%数据）**，计算误差变化率 $\Delta_{err}$：
$$\Delta_{err} = \frac{Error_{new} - Error_{old}}{Error_{old}}$$

只有当 $\Delta_{err} \leq -0.15$（即误差降低至少15%）时，新框架才被允许覆盖旧框架。否则，回滚至旧版本，并将校验集失败案例作为"硬负样本"存入下轮重构的优先级队列。

## 5. 非功能性需求与成本估算

### 5.1 延迟性能
- **热环路**：OOD数学检测（<5ms）+ 向量检索（<100ms）+ LLM推理（流式输出，首Token < 500ms）。
- **冷环路**：全局重构预计耗时 5~10 分钟（基于10万条记忆，采样15%数据，调用LLM 50次上下文窗口）。

### 5.2 Token消耗控制
- **单次热推理**：约 1,500 ~ 2,000 Tokens（包含检索到的Top-10摘要）。
- **单次全局重构**：约 20,000 ~ 50,000 Tokens（批量化压缩处理）。
- **优化策略**：使用`gpt-4o-mini`作为热环路主力，仅冷环路使用`gpt-4o`进行高精度归因。

### 5.3 存储规划
- 向量维度：384（Action）+ 1536（Outcome）= 1920维。
- 单条记录存储大小约为 4KB（含文本与向量）。
- 预估10万条记忆占用磁盘空间：**~4GB**（含索引），建议使用 **pgvector** 插件集中管理向量与关系型数据，避免异构数据库同步开销。

## 6. 实验验证方法论（Benchmarking）

### 6.1 校准度对比实验（Calibration Test）
- **对照组**：原生GPT-4 + 标准Few-shot Prompt。
- **实验组**：本架构（带样本量惩罚与对抗性挑战）。
- **度量指标**：Expected Calibration Error (ECE)。
- **预期结果**：实验组ECE从~0.25降低至≤0.12。

### 6.2 动态适应实验（Dynamic Adaptation）
- **场景**：向系统连续输入100条模拟经历，其中在第30条处 **突然改变环境奖励机制**（即因果规律发生偏移）。
- **观测指标**：实验组的预测误差曲线是否在经历10~15条异常数据后显著回落（反映临时工作区或局部修补生效），而对照组误差呈震荡发散。

---

## 7. 异常处理与容灾机制

1. **LLM输出格式解析失败**：采用正则回退提取JSON，若完全失效，则丢弃本次重构结果，保留旧框架并标记LLM异常。
2. **冷环路死锁**：设置最大重建时间（20分钟），超时则强制终止，等待下一调度周期。
3. **向量库索引重建**：每次全局重构后，异步重建向量索引（Reindex），期间热环路使用暴力搜索（Brute-force）降级服务，确保系统高可用。

---

## 8. 结论与下一步工作

本报告提出了一套完整的、可工程化的LLM动态认知架构。通过将"语义相似"转向"效用聚类"，引入"预测误差驱动"的重建触发器，并辅以严密的"置信度校准"与"沙盒验证"，本系统能够使LLM在长期交互中表现出类似人类的目的性分类与自适应成长。

**下一步工作方向**：
- 探索基于 **强化学习（RLHF）** 的簇标签自动评分机制，替代人工规则阈值；
- 研究如何利用 **MoE（混合专家模型）** 将不同的分类簇物理性地映射到不同的LoRA适配器上，实现真正意义上的"记忆模块化"。
