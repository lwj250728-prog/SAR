# 技术计划书：面向 LLM 的动态经验分类与预测认知系统（DCA-PED）V3.0

**版本**：V3.0（2026-08-19，基于真实数据验证与自我认知演进）
**核心目标**：在 V2.0 双环架构基础上，通过真实部署验证，完成三项演进——**前提分化自动涌现**、**检索咨询分类体系（自我认知）**、**经验自动积累（LLM 路由判断更新条件）**。

---

## 一、总体架构设计原则（V3.0 增补）

V2.0 的四项原则（效用优先于语义、预测误差驱动重建、双环路解耦、置信度校准）保持有效，V3.0 增补：

5. **LLM 路由是上限，确定性路径是下限**：所有模型辅助步骤（SAR 提取、OOD 复核、校准、重构、积累判断）都优先走 LLM 路由；无路由时降级为确定性数学。模板调用显式请求 `reasoningEffort: off`——思维链会耗尽小型 token 预算并饿死 JSON 答案（真实部署中 deepseek-v4-flash 默认思考模式曾导致所有模板调用静默降级）。
6. **分化随经验累积自动涌现**：不硬编码行动者/环境前提字段。同一行动在不同前提（新手教学 vs 资深直推）下反复出现且策略不同时，LLM 锚定按"情境-策略配对的重现模式"自动拆簇；≥3 证据下限就是自然的分化阈值。
7. **经验自动积累，判断交给 LLM 路由**：完成的轮次由 LLM 路由判断是否值得沉淀为经验（纯聊天由确定性预过滤拦截），不再依赖模型自觉调用 `remember_experience`。
8. **自我认知参与检索**：检索前先咨询分类体系——报告覆盖（covered/gap/no-taxonomy）、路由余量、路由置信；检索失败本身被自动 sar 化，成为可学习的元经验。

## 二、核心数据模型设计（V3.0 扩展）

V2.0 的四张表（experiences/predictions/temp_strategies/calibration_stats）保持，experiences 表增补字段：

| 字段 | 类型 | 设计意图 |
| :--- | :--- | :--- |
| `simulated` | bool | LLM 生成的仅检索候选，真实反馈验证前不塑造簇 |
| `verification` | 'unverified'\|'provisional'\|'verified' | 证据替换生命周期：决定性反馈快进 provisional，累积证据晋升 verified，矛盾反馈回滚 |
| `evidence_score` | float | 真实反馈累计证据分 |
| `meta` | bool | 管道自身观察（检索路由失败等），非用户任务经验；非中性 meta 经验进入冷环采样 |
| `utility_score` | 三维 | materialGain/emotionalValence/energyCost 0-10，5 为中性 |

新增 taxonomy/clusters 状态表：版本号、规则集（极性标注 ✅成功/⚠️风险）、簇（证据 id、决策规则、效用区间、情境质心、极性）。

## 三、热环路（在线推理引擎）V3.0

V2.0 的 OOD 检测 + 五层校准 + 临时工作区保持，V3.0 增补：

### Step 0：检索咨询分类体系（taxonomyContext）
- 查询情境对每个簇的情境质心打分（任意极性）。
- 输出：`coverage: 'covered' | 'gap' | 'no-taxonomy'`（低于 `coverageThreshold` 0.3 为缺口）、命中的簇、路由余量（最佳减次佳余弦）。
- 余量 < `retrievalFailureMargin`（0.1）时建议文本标注 **"路由置信低"**——告知模型确定性路由不可靠，应改用 LLM 路由。
- 语义上应命中但余弦不足的查询（实测 0.291 < 0.3）暴露阈值校准问题。

### Step 4：检索失败自动 sar 化
- 熟路预测且路由余量 < 0.1 → 自动合成 meta 经验（情境=路由歧义观察，行动=原查询行动使其可检索，结果=对策"改用 LLM 路由"），按行动余弦 ≥0.8 去重。
- meta 经验进冷环训练切片 → 可聚出"检索失败模式"簇。

### Step 5：校准提示词标记元经验
- top-K 样本中的 meta 经验标记为 `【元经验-管道自身】`——模型看到"这是已记录的失败模式 + 对策"。

## 四、冷环路（离线重构管线）V3.0

### 采样（增补）
- 确定性预过滤不变（误差优先 + 成功锚点 + 时间衰减）。
- **meta 通道**：`meta=true` 且非中性的经验无条件入采样（无用户误差信号通道）；`cap()` 预算永不截断 meta 经验。
- **meta 永远进训练、不进验证**：它们是学习信号而非留出验证数据，防止低 gain 效用污染回测，并让重构能看到它们。

### 聚类与锚定（V3.0 关键演进）
- 重构提示词从"按结果效用相似性聚类"改为"**按情境-策略配对的重现模式聚类**"：
  - 同一行动在不同前提下策略不同 → 拆簇；情境措辞不同但策略相同 → 合并；宁缺毋滥。
  - 前提分化（新手教学 vs 资深直推）随累积自动涌现——实测 13 条前提实例后 taxonomy v4 长出两个前提分化簇。
- 证据相干性硬约束保持：证据三维效用彼此接近（单维差 ≤3）、两两距离 ≤0.85、≥3 条真实 exp_id；确定性回退分组必须通过**同一道**证据闸门（消除校验绕过）。
- 情境质心由**证据经验**推导（而非全部结果相似成员）——防止结果相同的前提分化簇互抢成员、稀释质心。

### 验收（V3.0 双区间）
- **冷启动区间**（无已存簇）：对照空视图 baseRate 基线，`Δerr ≤ 0` 即验收（15% 余量在 2-3 条验证切片上统计上不可达，实测改善上限仅 6.98%）。
- **迭代区间**（有已存簇）：保持 `Δerr ≤ -15%`。
- **有界重构重试**：LLM 抽样是随机的（一次可能返回 0 簇或全不相干证据），产出无验证簇时按 `reconstructRetries`（默认 2）重试。

## 七、自动积累（新增组件）

| 阶段 | 触发 | 处理 |
| :--- | :--- | :--- |
| **触发** | `turn/end`（completed/error） | 从会话日志重建片段（情境=用户请求，行动=工具调用序列，结果=结束原因） |
| **预过滤** | 纯聊天（无工具调用 + 无失败 + 短输出） | 直接跳过，不消耗 LLM 调用 |
| **LLM 门（模板5）** | 实质工作轮次 | 判断是否值得沉淀 + 提取 SAR 三元组 + 三维效用；参考 top-3 历史相似经验做新颖性判断 |
| **写入** | 门判断值得 | 直写入库（普通 verified 经验，非 meta） |

## 八、实施路线图

| 阶段 | 周期 | 核心交付物 | 验收标准 |
| :--- | :--- | :--- | :--- |
| **Phase 1：真实数据验证** | 第 1-2 周 | 用其他会话的真实经验跑通冷环：双区间验收、前提分化、meta 经验 | taxonomy v1→v4 连续验收；前提分化簇长出 |

## 九、关键风险与应对策略

| 风险点 | 影响 | 缓解措施 |
| :--- | :--- | :--- |
| **LLM 抽样随机性** | 同一次重建可能验收或被拒 | 有界重试（reconstructRetries）；多次抽样中可用 draw 实测 3/3 |
| **词袋余弦判别力弱** | 前提判别 token 被共享任务词稀释（新手情境 cos 0.552 vs 资深簇 0.602） | taxonomyContext 显式标注低置信；LLM 校准层路由；后续换真实嵌入 |
| **验证切片 OOD** | 最新留出切片未被训练簇很好预测 | 诚实回退（不写更差的分类）；随累积自动解决 |
| **自动积累噪声** | 无价值轮次污染记忆库 | 确定性预过滤 + LLM 门宁缺毋滥标准 + 去重 |
| **coverageThreshold 临界** | 0.291 vs 0.3 边界查询误判为缺口 | 阈值数据驱动校准 |

## 十、成功指标（KPI）定义

1. **预测校准度**：各置信档位实际准确率与预测概率的均方根误差（目标 < 0.1）。
2. **重建有效率**：冷环触发后通过沙盒验收的比例（实测 v1/v2/v4 连续验收）。
3. **前提分化质量**：同一行动不同前提的查询获得不同策略参照的比例。
4. **检索建议准确率**：taxonomyContext 的 covered/gap 判定与人工判断一致率（目标 > 85%）。
5. **自动积累有效率**：LLM 门接受的经验中，后续真实反馈验证为有效经验的比例（目标 > 70%）。
